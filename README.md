# React Poker

Live at https://poker.stephens.page

A hot-seat poker web app for two players sharing one screen. Built with React and bootstrapped with Create React App.

## Features

- Two-player hot-seat gameplay with reveal/conceal hand controls for privacy
- Standard 52-card French deck with Fisher-Yates shuffle
- Chip tracking and pot management
- Community card dealing for Texas Hold 'em style play
